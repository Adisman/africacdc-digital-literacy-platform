# Starter curriculum

21 modules · 65 lessons · 150 quiz items · 30 CEU · English and French. Every module has lessons, one interactive activity, a quiz (7–9 items) and a printable job aid. Passing all 21 unlocks the 40-question final exam (3.5 CEU, accredited certificate). Completing a level issues a Member-State certificate.

Content source lives in `content/` (plain JavaScript data, bilingual). Edit it and run `node scripts/build-content.js`, which validates EN/FR parity, quiz structure and the CEU total before writing `public/data/`.

> **Review note:** content was authored for this release and must be reviewed by Africa CDC subject-matter experts and native French speakers before use with learners. Modules on DHIS2 and REDCap teach concepts and workflows only; the platform has no integration with those systems (out of ToR scope).
